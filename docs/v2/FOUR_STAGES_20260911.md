## 2. 真实当日观察到人工复盘

新入口：`stock-data-daily run --output <新目录>`，可显式提供 `--parent <前交易日封存包> --archive <人工回执目录> --publish-root <独立V2目录> --generation <递增整数>`。

执行行为：

1. 以上海实际日期为准；15:00 前只写 pending，原生请求数为 0，不产生 completed。
2. 收盘后走既有官方日历和完整分页采集，最多 6 请求、无重试；日期、完整性或来源不合格只保留待核查产物，不发布为当前结果。
3. 合格观察产生候选证据、来源解释、风险与待人工队列。不替人生成判断，也不自动确认/预占/下单。
4. 有父包时，必须经官方交易日历确认是确切下一交易日，才能生成次日复盘；人工回执依实际接收时间区分事前与追认。
5. 所有必需步骤成功才更新 V2 发布指针。生成的 HTML 自包含，无运行时外部数据依赖。

## 4. 完整恢复和容量边界

新增核心入口：

```powershell
stock-data-recovery backup --source <已正常关闭的V2库> --output <新备份目录>
stock-data-recovery restore --source <备份目录> --output <新恢复目录>
```

取得所有者句柄锁并保持原生只读连接；WAL 存在时拒绝，不删除 WAL。完整复制数据库及原始哈希档案，对比文件摘要、表/行数、索引、视图、序列与目录成员；恢复只写新目录，并独立全量重放纸面账本。文件损坏、占用、重复目录或复制失败不会删除源数据或生成虚假的完成标记。备份可能含账户数据，不进入 Git，不公开发布。
