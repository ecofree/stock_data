# 冻结实验与 QLib 多折历史评价

状态：**已实现实验登记与多折执行器，并完成一次冻结预算的真实历史 QLib 试跑。没有证明选股优势；不是组合成交回测或生产验收。**

## 问题与本段取舍

原有 rolling_partitions 只生成分段，训练入口仍做单次 train/valid/test。本段增加独立不可变实验目录，先登记再逐折拟合、输出预测和配对比较。复用本地安装的 QLib LGBModel，不新增网络数据源、付费调用或生产信号写入。

多折标签评价实际执行；没有用标签收益减成本来冒充组合回测。既有纸面结算引擎仍独立，模型预测到组合约束的完整连接是下一项工作。

## 已实现

- **冻结登记**：实验 ID、特征文件集合/内容摘要、导出元数据、标签定义/可用性假设、特征组、核心实现摘要、数据/模型依赖版本、观察窗口、抽样/折数/训练预算、种子、成本场景。同 ID 不覆盖，代码/数据/元数据/依赖变化后不能复用。
- **公平样本**：标签过滤之前按日期/证券 SHA-256 抽样；所有变体共用同一批可评价测试身份。缺预测或非有限预测直接失败，不通过漏掉困难样本改善指标。全训练缺失列显式记录。
- **逐折隔离**：扩展训练窗口；训练标签结束/可用时间严格早于验证起点，验证标签严格早于测试起点；时间按声明 Shanghai 假设解释后转 UTC。每折中位数只从训练集拟合；模型训练适配器只持有 train/valid，预测适配器不携带测试标签。早停只读取验证段。
- **不伪造保留集**：保留尾段且不评分，但整个导出快照标为曾被检查。登记早于本次拟合，不早于历史结果曾被看到；不能因此称为未触碰样本。
- **实际 QLib**：每折每组独立 recorder；原生文本模型、训练中位数、预测、测试身份、折指标和日指标全部保存。不更新 champion、影子预测权重或订单。
- **配对比较**：价格组、价格+资金组与每折训练均值常数共用样本；逐日 MSE 差以固定 5 个观测日移动块、500 次重采样作描述区间。不是多重比较校正或数据源因果贡献。
- **成本边界**：固定 0/10/30/50 个往返基点仅做标签敏感性，不含现金、仓位重叠、T+N、委托/成交量、真实费率、停牌/封板/冲击、公司行为核算。portfolio_return 始终 null。
- **失败和发布**：失败保留 started/failed，不生成 completed，不覆盖重跑。成功清单绑定权威文件和 Markdown，读取核对成员与内容。MLflow 辅助目录不纳入权威清单，不能代替已绑定指标。

核心 `trade_system/v2/rolling_research.py`；命令 `tools/v2/run_rolling_research.py`；冻结配置 `docs/v2/rolling_experiment_20260910.json`。
