1. **非有限数/溢出进入金额。** 原 `float()` 接受 NaN/Inf，乘法也可溢出。`units.py` 的有限数边界和转换原因覆盖源缺失、未知单位、非法数值、溢出；SQL 从同一单位词汇生成表达式。先新增失败回归，修复后通过。负资金净流入仍合法，未一概改为零。
2. **已乘倍数但仍贴原单位。** TuShare 标准视图将手/千元转换后还标记原单位，二次消费会再次放大。`normalize.py` 的三条 K 线路径统一使用同一转换合同，输出 shares/yuan；真实分区验证幂等单位和来源值对齐。原始表保留，不在现网改视图。
3. **换手率缺失时用成交额冒充。** `review_queries.py` 将 `turnover_rate_pct` 与 `trade_amount_cny` 分开；兼容 `turnover` 只保留换手率维度。板块快速查询不再无条件把所有成交额乘一千。历史标签不批量乘倍数修复。
4. **qfq 请求接受 none 响应。** 公共 `get_kline` 校验每行调整标签，不符就继续下一源；BaoStock 当前适配器只认证 raw，不对未验证的复权请求伪造合格标签。没有把历史回执重写成合格。
5. **市值标签歧义及总/流通混用。** 两条已声明亿元的估值生产路径改为明确 `100m_yuan`；`market_caps()` 产生不同的总市值/流通市值字段，未知旧 `billion_yuan` 不猜。持久化 JSON 保存 canonical 值、原因和 raw；已有数据库列保持原单位值，不进行隐式迁移。真实全库市值影响范围尚未核完，不能关闭整个市值审计项。
6. **自动压缩原库且缺乏恢复边界。** 候选脚本删除旧交换/压缩职责；`--yes` 在开库前拒绝，只有显式只读 inspection。临时数据库哈希不变及无 WAL 回归通过。此变化未替换现网脚本。
7. **研究依赖绕回旧入口。** 将日历解析移入研究 receipt 模块，旧 probe 仅兼容导入；研究包按实际 import 闭包生成，禁止 base、旧 relay 进入。包内文件校验拒绝多余旧代码。包可离开仓库运行状态读取和真实回执容量预检，但依赖使用现有研究 Python。
8. **补充研究绑定单只证券、稀疏样本仍易被误读为可晋升。** 用完整请求身份唯一匹配补充因子，歧义必须明确指定；不允许借用不同请求的结果。模型晋升始终单独审核，结构通过不自动替换。容量预检不触发采集或拟合，并明确 Alpha158 仅检查窗口容量，非因子效用认证。
