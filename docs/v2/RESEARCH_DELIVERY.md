# 本地研究工作台：使用与交付范围

本轮目标是交付可以每天使用的研究工具，不再把历史数据逐案补齐作为所有功能的前置条件。没有重写旧库、旧标签或正式资格开关，没有迁移生产任务。

## 直接使用

在 `D:\accio\stock_data-retirement` 双击 `Start Research.cmd`，打开本地研究工作台。默认地址为 `http://127.0.0.1:8766/`。已启动时复用现有服务；首次无模型时先构建。需要保留启动窗口，关闭后可再次双击启动。

1. 收盘后点击“更新真实数据与预测”。更新期间保留上一成功页面；失败不把旧日期改成今天。
2. 输入代码筛选，点击证券行查看模型评分、20日动量、模型贡献、原始来源文件和窗口缺口。
3. 填写署名、判断依据和失效条件，保存观察/不采用/研究假设。记录不可覆盖，也不生成委托。署名是操作者自行声明，不是登录认证。
4. 后续交易日再更新，工作台自动将历史冻结预测与精确 T+1 开盘、T+2 收盘匹配。未成熟、缺价分别显示，不补零。旧预测不会被新模型重算替换。

默认解释器为本机 `D:\anaconda\python.exe`。来源凭据由启动器通过 `KPL_ENV_FILE` 指向原项目的本机环境文件，页面和报告不包含凭据。服务仅监听回环地址，有 Host/Origin/CSRF 和表单大小检查；不要对外暴露端口。

本版是本机源码运行交付，不是可脱离本机数据和依赖的便携安装包。核心 0.3.2 wheel 不含该研究界面。QLib 依赖见根目录 `requirements-qlib.txt` / `requirements-qlib.lock`；重新构建还需要配置中绑定的本机冻结数据，不能只克隆仓库便宣称可重建。

- 43只证券，2025-01-02 至 2025-11-26 的218个共同交易日，9,374个价格/复权/资金输入行。

## 同一入口与数据存放

维护入口：`tools/v2/research_workbench.py build|update|serve|status`。

- `build --config config/research_delivery.json`：输入预算先检查；新目录构建特征、注册三组实验、实际拟合并冻结模型。失败目录保留诊断，不发布为成功。
- `update`：使用冻结证券池获取当日窗口、核对原始回执、计算同公式特征和预测。连续3次来源失败停止该来源余下请求；不切换成合成数据。
- `update --receipts <目录>`：仅重放与当前日期/范围/证券池精确一致的已封存回执，不能拿旧日期冒充当前。
- `serve --port 8766`：本机交互入口；`status`：摘要状态。

产物位于 `reports/research-delivery`：版本化 `builds`、原始 `observations`、追加式 `notes`、不可变 `publication`。研究指针和预测指针带文件摘要；页面数据内联，没有运行时外部资源/fetch依赖。首页只显示最近100条判断和30批跟踪，原记录保留在磁盘。

本轮成功模型目录为 `builds/3057dbc4d19a43aabd90d7da15707752`。原始当日成功回执目录为 `observations/bfe1b0637a084d4cb5e666acb6163cbd/receipts`；最新预测通过 `prediction-current.json` 指向，重复更新不覆盖先前批次。

## 后续只保留四项产品工作

1. **实际使用反馈**：用户记录第一批真实判断；后续交易日更新后，核对解释是否有用、判断与结果是否配对。无需账户导出即可使用研究工作台。
2. **提高当前覆盖与模型新鲜度**：优先处理妨碍当日候选的窗口问题、按同一配置扩大近期训练窗口；先声明共同样本和成本口径，再比较，不反复挑最佳历史区间。
3. **验证而非预设选股优势**：积累真正冻结在未来结果之前的预测；增加市场/行业对照、可成交约束和组合级回测。当前负向结果保留。
4. **稳定交付与受控部署**：形成独立依赖/数据恢复安装包和多日运行证据；若要替换原定时任务、迁移生产或接账户，单独确认。

历史9个精确成交量、14个资金缺日保留在独立数据质量队列，不阻塞这四项中不依赖它们的工作。不再以新增补证报告数量作为进展指标。
