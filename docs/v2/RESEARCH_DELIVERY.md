# 本地研究工作台：使用与交付范围

本轮目标是交付可以每天使用的研究工具，不再把历史数据逐案补齐作为所有功能的前置条件。没有重写旧库、旧标签或正式资格开关，没有迁移生产任务。

## 当前版本：六环节连通

2026-09-11 路线版按“真实数据 → 非空特征 → 规则基线与QLib对照 → 候选解释 → 判断记录 → 后续复盘”实施。它替代初版14只预测的当前展示，但不覆盖初版预测、原始回执或历史实验。

| 环节 | 当前实现与边界 |
|---|---|
| 真实数据 | 依据交易所日历选择最近已收盘交易日，行情日期、数据接收时间、预测冻结时间分开；陈旧回执不能冒称当前，发布失败恢复旧指针 |
| 非空特征 | 当前价格模型21日依赖；价格加资金检查21日价格及5日资金；Alpha158仍需61日。历史共同对照队列继续61日，不借改变样本提高成绩 |
| 基线对照 | 动量排序规则、共同证券等权观察，与三组QLib使用相同的3,440个测试身份；动量分数不是收益预测，不给它伪造MSE |
| 候选解释 | 可按模型或动量排序、按代码或名称筛选；展示中文指标、贡献、近21日缺口与全窗口缺口，并解释为何有评分或被排除 |
| 判断记录 | 可追加修订并绑定原预测、证券和自行声明的署名；原文不变。事前判断、事后补记和时间待核对分开，不支持回填接收时间 |
| 后续复盘 | 同日同模型取首次有效冻结，重复更新不重复计成绩；附加批次的判断仍可关联。价格、模型、动量和等权只在共同成熟证券上比较；事后修订不替换事前判断 |

当前40只有非空预测，剩余000524、000838、603137仍明确保留不足。新增26只不是补零、放宽来源价格冲突，或增加数据请求取得的，而是修正“价格模型误用Alpha158的61日窗口”的拦截。使用同一批9月11日原始回执重放，数据接收时刻没有变成重放时刻。

原生日历实际只提供截至当天的历史日期，并不包含未来交易日。下一开盘日期不明时保存“等待未来日历核对”，不直接判为事后预测，也不提前授予前瞻资格。等实际后续日历到齐，再核对预测和每版判断是否在准确开盘时间之前。

浏览器隔离测试完成一次保存和一次追加修订，两版均保留；真实工作台仍无代填的用户判断。42项定向测试覆盖输入窗口、日期边界、共同样本、失败回退、版本记录和后续配对，特别按预测最终冻结时刻而非采集开始时刻判断开盘前后。最终源码的全量结果另见 `tmp/research-flow-delivery-20260911-r2/verification.json`；这些技术检查不等于真人使用或选股效果验收。

## 直接使用

在 `D:\accio\stock_data-retirement` 双击 `Start Research.cmd`，打开本地研究工作台。默认地址为 `http://127.0.0.1:8766/`。已启动时复用现有服务；首次无模型时先构建。需要保留启动窗口，关闭后可再次双击启动。

1. 收盘后点击“更新真实数据与预测”。更新期间保留上一成功页面；失败不把旧日期改成今天。
2. 输入代码筛选，点击证券行查看模型评分、20日动量、模型贡献、原始来源文件和窗口缺口。
3. 填写署名、判断依据和失效条件，保存观察/不采用/研究假设。记录不可覆盖，也不生成委托。署名是操作者自行声明，不是登录认证。
   需要修改时点击“追加修订，保留原文”，仍绑定原预测；点击“退出修订”才恢复到当前预测。自由文本失效条件须人工核对，不按涨跌自动判定。
4. 后续交易日再更新，工作台自动将历史冻结预测与精确 T+1 开盘、T+2 收盘匹配。未成熟、缺价分别显示，不补零。旧预测不会被新模型重算替换。

默认解释器为本机 `D:\anaconda\python.exe`。来源凭据由启动器通过 `KPL_ENV_FILE` 指向原项目的本机环境文件，页面和报告不包含凭据。服务仅监听回环地址，有 Host/Origin/CSRF 和表单大小检查；不要对外暴露端口。

本版是本机源码运行交付，不是可脱离本机数据和依赖的便携安装包。核心 0.3.2 wheel 不含该研究界面。QLib 依赖见根目录 `requirements-qlib.txt` / `requirements-qlib.lock`；重新构建还需要配置中绑定的本机冻结数据，不能只克隆仓库便宣称可重建。

## 本轮真实结果

### 历史实验已经运行，不只是计算因子

- 43只证券，2025-01-02 至 2025-11-26 的218个共同交易日，9,374个价格/复权/资金输入行。
- 61日共同热身后6,794行特征；实际 QLib 0.9.7 + LightGBM 完成4折、12次拟合，三组共享3,440个样本外证券日、80个样本外日期。
- 三组为6个价格特征、价格加2个资金特征、价格加官方Alpha158；另有常量对照。滚动40/15/20日，最后20个特征日期不评分、不调参。训练/验证边界执行目标成熟时间清除。
- 当前预测模型预先指定为最后一折价格基线，不按样本外赢家换模；训练截至2025-08-28，验证截至2025-09-18，明显存在模型老化风险。

| 组别 | 样本外 MSE | 日均 Rank IC |
|---|---:|---:|
| 常量对照 | 13.3769 | 不适用 |
| 价格基线 | 13.4749 | -0.0467 |
| 价格 + 资金 | 13.4676 | -0.0348 |
| 价格 + Alpha158 | 13.6374 | -0.0418 |

结论：当前模型未证明选股优势。资金组相对价格组的误差差为-0.0073，Alpha158组为+0.1625，两者的描述性区间均跨零。不能称资金或Alpha158已产生稳定增益。Top5统计是价格目标均值，不是扣除真实换手、成交限制后的投资组合收益。

新增固定动量规则的Top5价格目标均值为-0.3051%，共同证券等权目标均值为+0.3659%。这也是描述性历史比较，不代表可成交的资金曲线；规则是在本阶段明确声明的，不冒称此前未见样本。

样本由54只历史可用证券中按数据完整性选出，不是按回报挑选，但仍是事后可用性选择，存在选择/生存偏差；没有历史时点股票池资格。四只因复权不足排除：002767、002841、301251、600288；七只因前缀价格不完整排除：000506、000593、000656、001395、002141、002490、601133。历史资金/复权为后来取得，历史可得时间是明确假设，不改称原时点回执。

2026-09-11 实际调用同花顺原生价格和中继日线、复权、资金、身份及双交易所日历；统一参数入口共218个请求，无额外收费接口、无无限重试。90个自然日返回64个交易日。

这是一份固定小样本研究观察清单，不是全市场选股、买入推荐或已验证策略。金额/数量冲突没有为凑候选而放宽。当前模型只消费价格特征，资金和Alpha158留在共同样本实验及解释页，不自动进入实盘评分。

## 同一入口与数据存放

维护入口：`tools/v2/research_workbench.py build|update|serve|status`。

- `build --config config/research_delivery.json`：输入预算先检查；新目录构建特征、注册三组实验、实际拟合并冻结模型。失败目录保留诊断，不发布为成功。
- `update`：使用冻结证券池获取当日窗口、核对原始回执、计算同公式特征和预测。连续3次来源失败停止该来源余下请求；不切换成合成数据。
- `update --receipts <目录>`：仅重放与当前日期/范围/证券池精确一致的已封存回执，不能拿旧日期冒充当前。
- `serve --port 8766`：本机交互入口；`status`：摘要状态。

产物位于 `reports/research-delivery`：版本化 `builds`、原始 `observations`、追加式 `notes`、不可变 `publication`。研究指针和预测指针带文件摘要；页面数据内联，没有运行时外部资源/fetch依赖。首页只显示最近100条判断和30批跟踪，原记录保留在磁盘。

当前模型目录为 `builds/a7066e57e1934d468b961085053ea6e0`；初版 `builds/3057dbc4d19a43aabd90d7da15707752` 保留。原始当日成功回执目录为 `observations/bfe1b0637a084d4cb5e666acb6163cbd/receipts`；最新预测通过 `prediction-current.json` 指向，重复更新不覆盖先前批次。

## 后续只保留四项产品工作

1. **实际使用反馈**：用户记录第一批真实判断；后续交易日更新后，核对解释是否有用、判断与结果是否配对。无需账户导出即可使用研究工作台。
2. **提高当前覆盖与模型新鲜度**：优先处理妨碍当日候选的窗口问题、按同一配置扩大近期训练窗口；先声明共同样本和成本口径，再比较，不反复挑最佳历史区间。
3. **验证而非预设选股优势**：积累真正冻结在未来结果之前的预测；增加市场/行业对照、可成交约束和组合级回测。当前负向结果保留。
4. **稳定交付与受控部署**：形成独立依赖/数据恢复安装包和多日运行证据；若要替换原定时任务、迁移生产或接账户，单独确认。

历史9个精确成交量、14个资金缺日保留在独立数据质量队列，不阻塞这四项中不依赖它们的工作。不再以新增补证报告数量作为进展指标。
