## 语义与时间边界

每个字段有值（包括明确的 0 或 null）、一基页码、人工解释；候选同时携带 URL、PDF SHA-256 和结构化可用时间。可重现表示可从登记转录重算，不表示 PDF 被自动理解正确。所有记录 `independent_review=pending`、使用权未复核、`account_receipt_proven=false`。

新字段时间为 **max(原 PDF 本地接收时间，本次转录登记时间)**，不是公告发布日期。新 PDF 的接收发生在本次登记之后；旧 PDF 保留旧接收时间，但新字段不能倒填。当前修复截止为 `2026-09-10T06:46:36.069813+00:00`；原知识截止仍为 `2026-07-29T10:00:00+00:00`。新文档的历史可用数量为 0，旧知识裁决 11 unknown 未改写。

冲突逐字段保留：日期/比例冲突不按来源顺序覆盖；相同小数的不同精度不算冲突；对齐旧原生税前现金金额，分配的转增部分作为增补而不是把现金组成误报为冲突。本次已检测字段冲突 0，不等于完成独立真实性审查。七份登记日、支付日、完整股份组成各补 3 项，加中迪两项区间字段，共 23 项；“已映射”与“整案解决”分开。

## 下一段实施顺序与验收边界

不等待全部未来生命周期资料才能开展代码实现，也不把缺数据改成成功。下一段优先把 **有声明假设的日线历史诊断** 接到现有父账计算实现：

1. 新增独立历史诊断作用域/登记与输入事件契约，不能将历史资料改标签冒充 `synthetic`。复用现金、股份、成本、税负核对，不平行再造账户算法。原三变体、全部共同 OOS 身份和原实验保持不变。
2. 在任何新绩效计算前冻结假设表：日线成交价/容量假设、停牌旧价估值有效期、退出等待上限、现金/股份安排与假设到账的区别、股份尾差与税额情景。**本段没有选择或登记这些假设。** 缺真实接收时点的资料仅用于事后修复诊断，不证明原时点可交易。
3. 用现金加转增、明确复牌、终点未知停牌三类用例验收。未知终点不得自动延伸为每天确认停牌；不能成交/估值时保留现金、持仓和应收，完整区间收益为 null。任何假设填补必须显式带 assumption 标记，不能写回来源字段。
4. 首先验收历史诊断代码及小范围冻结用例，再运行新登记的全部三变体；如资料条件仍不够，可报告同区间覆盖及未完成资产，禁止比较不同截断区间收益、更新 champion 或声称选股优势。
