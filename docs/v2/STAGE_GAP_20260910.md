## 原因与实现取舍

前段 `missing_held_factor` 同时覆盖缺持仓行/缺因子，不能直接裁为停牌。只有两个首次阻塞点也不足以覆盖剩余潜在持有区间。本轮使用新的 `gap_audit.py` 查清日线与因子是否分别存在，并扫描三组模型/基线全部预选窗口；不改已登记的组合实现及父实验。

`gap_evidence.py` 保留业务时间、来源接收时间、程序赋值的本地已知时间、来源/API/修订声明、响应原字节 SHA 与精确引用行。高优先级不能盖过冲突；空返回不证明停牌；新的历史证据不能倒填到旧回放时点；所有候选均禁止自动应用。

完整接口、输入格式与解释边界见 [GAP_EVIDENCE_CONTRACT.md](GAP_EVIDENCE_CONTRACT.md)。当前输入是明确 schema 的**结构化适配器响应**，不是通用原生 API 抽取器。归档字节正确不等于响应外部来源真实；source_authenticity 始终 not_independently_verified，未增加任何经独立认证的来源。
