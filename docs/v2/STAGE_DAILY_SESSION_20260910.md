## 能力与取舍

1. **每日候选范围**：官方涨停观察池，按观察连板高度降序和证券身份排序，最多 20 个。不是全市场最优候选，也不是 QLib 预测排名。本轮不为凑“智能”标签接入尚无稳定优势的模型。
2. **解释与风险**：保留来源归因、连板事实、原始行摘要，以及封板不可成交、次日跳空/无法成交、ST/新股/未知特殊状态、多连板波动等提示；来源归因不冒充公告验证。
3. **人工判断**：仅允许观察、不采用、纸面假设三种研究意向，必须填写依据和失效条件。文件绑定报告及候选身份。归档使用本地实际接收时间，不信任浏览器自填时间作为事前证明。同一意向重试幂等，改内容拒绝；只是姓名声明，不是身份认证。
4. **次日复盘**：必须由后续原生交易日历确认紧接的下一交易日，不能跳过缺失日。原 20 个候选全部保留，包括拒绝、没判断、没行情的证券。开盘后才归档的判断保留为事后记录，不进入事前判断。
5. **价格证据**：可选从已有本地 TuShare 日线表只读提取精确日期/证券的原始 OHLC，重复、复权口径不明、非正价格、未来接收时间拒绝。该入口明确标记“本地表，未经原生认证”，不替代 HiThink，也不触发 TuShare 限流重试或 akshare 回退。未取得价格则留空，不用次日未涨停推断亏损、停牌或零收益。
6. **收益边界**：次日来源涨跌幅仅是市场观察，不是 T+1 可实现收益、持仓收益或操作者收益。`actual_operator_return=null`，`execution_ready=false`。

## 日常命令

已安装命令为 `stock-data-daily`；源码入口为 `python -m trade_system.v2.daily_session_cli`。所有发布目录必须新建，不覆盖冻结包或失败现场。

```powershell
# 当日收盘后：仅接受执行当天的真实北京时间日期。
stock-data-daily capture --date <当天YYYY-MM-DD> --output <新的当日数据包目录>

# 更新静态展示，不重新请求数据、不修改冻结包。
stock-data-daily view --report <当日数据包目录> --output <新的静态展示目录>

# 用户在页面中填写并导出后，由本地程序校验归档；不是交易确认。
stock-data-daily judge --report <当日数据包目录> --note <导出的判断JSON> --archive <独立判断归档目录>

# 没有后续交易日数据时，只生成待办状态，禁止冒充已完成复盘。
stock-data-daily review --parent <当日数据包目录> --output <新的待复盘目录>

# 下一交易日收盘后，先 capture 当天，再精确核对原候选。
stock-data-daily review --parent <上一交易日包> --following <下一交易日包> --archive <判断归档目录> --output <新的复盘目录>

# 如需追加已有本地日线观察，可在 review 中增加 --legacy-db <数据库路径>。
# 此路径只读；库被写进程占用时失败，不杀进程、不删生产锁、不伪造价格。
```
