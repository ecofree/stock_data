# 下一阶段：不可变事件 → 纸面交易 → 可重建结算账

状态：**本阶段事件桥接与纸面结算纵向切片已实现；真实策略、完整回测和生产验收仍未完成。**

## 问题、方案与取舍

上一阶段已生成真实历史条件观察，但策略仍依赖调用方的题材/资金布尔值，纸面确认也没有接到可重建的成交和批次成本账。本阶段将声明过口径的竞价、报价、累计资金与题材广度事件转换为冻结条件，复用既有策略/风控，再将纸面预占原子转入纸面订单。

保留单 writer、独立 V2 库和三账边界。不从旧库日线/分时记录猜测竞价最终性、排队或成交；不接真实账户、不购买数据、不修改现网调度、不推送 Git。本轮没有重训 QLib，也没有证明选股效果提高。

## 实现范围

1. `event_bridge.py`：竞价预估与最终结果分产品；业务/实际导入接收时间分别保存；未来事件拒收，历史假设事件不能提供系统重放资格。引用原始摘要与事件 ID，篡改报错，重复输入不再写入。V2 加法迁移版本 3，保留版本 1/2 原文。
2. 同一产品、同一指标版本、不同观测时点的累计资金作差，不跨来源求和；同一时点修订不算第二个观测。题材覆盖有固定分母和成员版本，报价必须连续交易阶段；这些都是明确测试策略条件，不是已校准投资阈值。
3. 信号绑定事件政策、事件 ID 和有效期。确认及纸面订单接收时重查当前事件、最新信号、账户版本、账本哈希及未解决账户事件；新事件改变依据后需重新生成和确认。冻结参数改变必须新策略版本。
4. `paper_ledger.py`：现金/成本/费用全部整数分，股数整数；批次 FIFO 成本和明确交易日历 T+N。委托整手、显式允许的零股全卖、可卖量预占、部分成交、按订单累计最低佣金、版本化费率均可重放。报价必须在委托之后、同交易日且新鲜。
5. 盘口可见量只作为**纸面容量代理**，同一快照跨订单共享容量、重复快照不重复使用；无盘口、零对手盘、停牌/非连续阶段、价格不满足限价时不成交。没有交易所队列、冲击或真实成交保证。
6. 撤单申请不释放占用，撤单确认释放剩余量；等待撤单确认期间仍可能部分成交。`unknown` 不因超时或撤单意图恢复，不自动成交；显式状态解决后才能继续。终态不复活。
7. 显式现金流按单位净值调整份额，不冒充利润；现金分红要求登记权益数量证据；整数拆并股保留总成本和可卖日期。未支持零碎股现金补偿、配股、全部税收调整和公司行为联合时点估值；有活动订单时拆并股拒绝，需先显式解决。
8. `paper_storage.py`：V2 加法迁移版本 4，追加事件序号/前态/后态/输入哈希及账本头。恢复时从初始配置完整重演，删尾、改值和摘要冲突报错。账户投影与预占转入订单在一个事务中完成，不能释放后另起事务下单。
9. JSONL 单 writer 服务新增 `market_event`、`event_signal`、`paper_open`、`paper_event`、`paper_buy`、`paper_status`。通用事件入口禁止直接提交买单；买入须消费有效纸面确认。卖出目前是显式纸面退出指令，受库存/日历/限价约束，**尚未接入完整统一卖出决策与题材风险引擎**。

`paper_status.asof` 为最后落账时间，不是行情刷新时间。`valuation_complete` 仅描述该时间的估值完整性；跨日或超期不能将旧状态说成当前净值。账户决策仍使用快照有效期与对账检查。
